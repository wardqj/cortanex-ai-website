# Artwork provenance

`public/assets/connected-flow-hero.webp` is the custom decorative artwork generated for the CortaNex V2 landing page. It was optimized to WebP from the original raster generation. It represents connected operational flow through metallic blue ribbons on a dark background. It contains no client factory, machine-control screenshot or customer evidence. The exact approved vector logo is overlaid separately in HTML and has not been redrawn.

Logos, local fonts and favicons were copied without modification from the published V2 landing-page source. Font license notices accompany the files.
